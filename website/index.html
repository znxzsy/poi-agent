系统架构

三层 Harness 工程体系：约束 → 验证 → 修正

约束层 — 定义对抗边界

Teacher Agent（攻击方）

模拟黑灰产从业者，基于收益-成本-风险决策模型，持续生成对抗样本

Student Agent（防御方）

模拟风控专家，合规优先，误拦率 ≤ 1% 硬约束，处置时效 ≤ 24h

↓

检测率 策略有效性阈值
误报率 ≤ 1% 硬性约束
期望收益 攻击成本-收益分析
↓

修正层 — 反馈闭环

对抗样本自动生成
漏洞发现与修复

核心模型

四维成本-收益-风险框架，量化对抗决策

C

四维作恶成本模型

从四个维度量化黑灰产攻击成本：

  • 时间成本 — 注册 / 操作 / 等待（分钟）
  • 资金成本 — 账号 / 设备 / IP（元）
  • 技术成本 — 绕过难度 / 工具开发（1-10级）
  • 账号成本 — 封号率 / 复用次数
π

期望收益模型

攻击方的期望收益计算：

E[revenue] = R&subsuccess;×P&subsuccess; - R&subfailure;×P&subfailure;

当 期望收益 > 总成本 + 风险成本 时，攻击有利可图

R

风险成本模型

综合封号与法律风险：

E[risk] = P&subban;×L&subban; + P&sublegal;×L&sublegal;

平台目标：作恶成本 + 风险成本 > 作恶收益
