Core Models

Four-dimensional cost-revenue-risk framework for adversarial decision modeling

E

EvilCostModel

Four-dimensional cost model for quantifying adversarial effort:

  • Time: registration, operation, waiting (minutes)
  • Money: account, device, IP cost (yuan)
  • Technology: bypass difficulty, tool dev (1-10 scale)
  • Account: ban rate, reuse count
π

EvilRevenue

Expected revenue calculation:

E[revenue] = R&subsoc;×P&subsoc; - R&subf;×P&subf;

Where R&subsoc; is success revenue, P&subsoc; is success rate, R&subf; is failure loss, P&subf; is failure rate.

R

RiskCost

Risk-adjusted cost for adversarial decisions:

E[risk] = P&subb;×L&subb; + P&subl;×L&subl;

Where P&subb;/L&subb; is ban probability/loss, P&subl;/L&subl; is legal risk/loss.

Agents

Teacher/Student dual-agent architecture with adversarial feedback loop

🔴

TeacherAgent (Attacker)

Simulates adversarial behavior with profit-driven decision making:

  • select_attack() — argmax(revenue - cost - risk)
  • generate_adversarial_sample() — produce attack details
  • evolve_attack() — adapt based on defense feedback
🔵

StudentAgent (Defender)

Simulates defense with compliance-first decision making:

  • select_defense() — match strategies to attack type
  • defense_decision() — BLOCK/PASS based on confidence
  • learn_from_attack() — generate new defense strategy
